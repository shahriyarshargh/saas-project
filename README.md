# پروژه اولیه SaaS نام سایت

یک نمونه اولیه‌ی فرانت‌اند با HTML، CSS و JavaScript خام؛ بدون React یا کتابخانه‌های خارجی جاوااسکریپت.

## اجرا

فایل `index.html` را در مرورگر باز کنید. برای تجربه بهتر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## صفحات

- `index.html`: صفحه اصلی و مودال ورود
- `detail.html`: جزئیات سرویس و فرم ۵ فیلدی
- `dashboard.html`: پنل کاربری، درخواست‌ها و بخش دانلودها
- `css/style.css`: تمام استایل‌ها و ریسپانسیو
- `js/app.js`: مودال، منو، پیام‌ها و ذخیره‌سازی محلی
- `js/login.js`: رفتار ورود نمایشی
- `js/detail.js`: اعتبارسنجی فرم، جداکننده سه‌رقمی و تبدیل عدد به حروف
- `js/dashboard.js`: نمایش درخواست‌های ثبت‌شده

## پنج فیلد فرم

1. نام و نام خانام سایتدگی (متن)
2. شماره موبایل (عدد)
3. تاریخ شروع مدنظر (تاریخ)
4. بودجه مدنظر (عدد با جداکننده سه‌رقمی و نمایش حروف)
5. تعداد کاربران (عدد با جداکننده سه‌رقمی و نمایش حروف)

## نکته مهم برای ارائه به استاد

این نسخه فعلاً نمایشی است؛ ورود واقعی، احراز هویت، ثبت امن اطلاعات و دانلودها باید بعداً از طریق API انجام شود. `localStorage` فقط برای نمونه اولیه است و جایگزین بک‌اند یا احراز هویت امن نیست. فونت از Google Fonts بارگیری می‌شود؛ در صورت نیاز به اجرای کاملاً آفلاین، فونت محلی اضافه کنید.

## پروژه نوا  Master page راهنمای اجرای

این بسته یک نمونه مستقل و قابل اجرا برای نمایش مفهوم Master page است.
در این ساختار از Html،Css و javaScript ساده استفاده شده و فریمورک یا php لازم نیست.
ساختار:
-master/master.html: قالب مادر، هدر، محل محتوای صفحات و فوتر مشترک
-components/header.js: تولید منوی اصلی و دکمه ورود/پنل کاربری
-components/footer.js: تولید فوت مشترک
-js/master.js: بارگذاری صفحات داخل master page و مدیریت منو
-views/*.html: محتوای جداگانه صفحات 
-css/style.css: فایل css قبلی ارسال شما
-css/master.css: استایل اختصاصی منو و قالب مادر
 
 روش اجرا:
 1) فایل zip را Extract کنید
 2) پوشه saas-nova-masterpage را در VS Code باز کنید
 3) افزونه live server را نصب/فعال کنید
 4) روی index.html راست کلیک کنید و Open with Live Server را بزنید
 5) منو را تست کنید. محتوای صفحات در همان قالب مادر تغییر می کند

 نکته فنی:
 صفحات views قطعه های html هستند و به صورت fetch داخل #page-content بارگذاری می شوند
 به همین دلیل اجرای مستقیم با file:// مناسب نیست و باید از Live server یا یک وب سرور محلی استفاده شود
 
 ورود:
 دکمه ورود در این نمونه صرفا نمایشی است و فقط نام کاربری را در LocalStorage ذخیره می کنید
این ورود احراز هویت واقعی نیست و برای اتصال به API / Back end باید منطق آن جایگزین شود
